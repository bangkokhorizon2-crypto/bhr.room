# Bangkok Horizon Ram 60 - คู่มือติดตั้ง Google Apps Script Backend (Google Sheets & Google Drive)

ระบบนี้เชื่อมต่อฐานข้อมูลแบบเรียลไทม์ระหว่างหน้าเว็บกับ **Google Sheets** และ **Google Drive**:
- **ไม่ต้องสร้างโฟลเดอร์ Google Drive เอง**: โค้ดจะค้นหาหรือสร้างโฟลเดอร์ `"BangkokHorizonRam60_Storage"` ให้อัตโนมัติ พร้อมโฟลเดอร์แยกห้องชุด
- **ไม่ต้องสร้าง Google Sheet เอง**: โค้ดจะสร้างชีต `"BangkokHorizonRam60_Database"` พร้อมหัวตาราง 6 แท็บให้อัตโนมัติ:
  1. `Rooms` (ข้อมูลห้องชุด)
  2. `Leases` (สัญญาเช่าและข้อมูลผู้เช่า)
  3. `Bookings` (ใบจองห้องชุด)
  4. `Facilities` (สิ่งอำนวยความสะดวกส่วนกลาง เช่น สระว่ายน้ำ ฟิตเนส สวนลอยฟ้า)
  5. `JuristicServices` (บริการสำนักงานนิติบุคคลและระเบียบการเช่าอาคารชุด)
  6. `Settings` (การตั้งค่าระบบ, รหัสผ่านแอดมิน, เบอร์ติดต่อ, LINE OA, ข้อมูลโครงการ)
- **ไม่ต้องจำ Folder ID หรือ Sheet ID**: ระบบจัดเก็บและจำค่าใน `ScriptProperties` ให้อัตโนมัติ

---

## ขั้นตอนการติดตั้ง / อัปเดตโค้ด:

1. **เปิด Google Apps Script:**
   - ไปที่ [https://script.google.com](https://script.google.com)
   - เปิดโปรเจกต์เดิม หรือกด **"โครงการใหม่" (New Project)** ทางด้านซ้ายบน
   - ตั้งชื่อโครงการ เช่น `BangkokHorizonRam60-Backend`

2. **วางโค้ด:**
   - ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
   - คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` มาวางแทนที่
   - กดปุ่ม **บันทึก (Save / ไอคอนรูปแผ่นดิสก์)** หรือกด `Ctrl + S` (`Cmd + S`)

3. **ตั้งค่าระบบอัตโนมัติ (ครั้งแรก หรือเมื่อต้องการสร้างแท็บใหม่):**
   - ด้านบน ตรงดรอปดาวน์เลือกฟังก์ชัน ให้เลือก **`setupProject`**
   - กดปุ่ม **"เรียกใช้" (Run / ไอคอน Play)**
   - Google จะขออนุญาตเข้าถึง Google Drive และ Google Sheets:
     - กดปุ่ม **"ตรวจสอบสิทธิ์" (Review Permissions)**
     - เลือกบัญชี Google ของท่าน
     - หากขึ้นหน้าต่างเตือนความปลอดภัย "Google ไม่ได้ยืนยันแอปนี้" ให้กดที่ **"ขั้นสูง" (Advanced)** ด้านล่าง แล้วกด **"ไปที่ BangkokHorizonRam60-Backend (ไม่ปลอดภัย)" (Go to ... unsafe)**
     - กดปุ่ม **"อนุญาต" (Allow)**
   - รอ 5-10 วินาที เมื่อทำงานเสร็จ จะมีข้อความแสดงว่าสร้าง Google Drive Folder และ Google Sheet ให้เรียบร้อยแล้ว!

4. **เผยแพร่เป็น Web App (Deploy):**
   - กดปุ่ม **"การทำให้ใช้งานได้" (Deploy)** สีน้ำเงินด้านบนขวา -> เลือก **"การทำให้ใช้งานได้ใหม่" (New deployment)**
   - กดไอคอนรูปเฟือง ⚙️ ด้านซ้าย -> เลือกประเภทเป็น **"เว็บแอป" (Web app)**
   - ตั้งค่าดังนี้:
     - คำอธิบาย: `v2-facilities-sync`
     - ดำเนินการในฐานะ (Execute as): **ฉัน (บัญชีของคุณ / Me)**
     - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ Frontend สามารถอ่าน/บันทึกข้อมูลส่วนกลางและห้องชุดได้จากทุกเครื่อง)*
   - กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
   - คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
   - นำ URL นี้มาวางในเมนู **"ตั้งค่าระบบ -> ข้อมูลโครงการ & Cloud"** ในหน้าแอดมินของเว็บ Bangkok Horizon Ram 60 ได้ทันที!
